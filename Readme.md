### IntellMeet — AI-Powered Meeting and Collaboration Platform

A full-stack platform that brings meetings, real-time communication, transcripts, AI summaries, action items, tasks and analytics into one collaborative workspace.

* Implemented secure JWT authentication and protected application routes
* Built browser-based video meetings with WebRTC and Socket.IO signalling
* Added real-time messaging, presence, captions and screen sharing
* Integrated AI-assisted meeting summaries, key points and action-item generation
* Implemented task management, notifications, recordings and analytics
* Deployed the frontend on Vercel and backend on Render

**Technology:**
`React` `TypeScript` `Node.js` `Express.js` `MongoDB` `Socket.IO` `WebRTC` `OpenAI API` `Docker` `GitHub Actions`
